# School Management System API

Информационная система для завуча школы.

## Возможности
- управление учителями и учениками
- составление расписания
- выставление четвертных оценок
- формирование отчетов об успеваемости

API реализовано с использованием Django REST Framework.
Доступ к API возможен только для авторизованных пользователей.
