# Отчеты

## Отчет об успеваемости класса за четверть

`GET /api/reports/`

Эндпоинт предназначен для получения отчета об успеваемости заданного класса за выбранную четверть.  
Отчет формируется **динамически** и не хранится в базе данных.

### Query parameters
Параметры передаются через **query string**, так как они используются для фильтрации и агрегации данных при формировании отчета.

| Параметр | Тип | Обязательный | Описание |
|--------|----|--------------|---------|
| class_id | int | да | Идентификатор класса |
| quarter | int | да | Номер четверти |

### Описание полей ответа

| Поле               | Тип    | Описание                           |
| ------------------ | ------ | ---------------------------------- |
| students_count     | int    | Количество учеников в классе       |
| class_teacher      | string | ФИО классного руководителя         |
| class_average      | float  | Средний балл по классу за четверть |
| subjects           | array  | Список предметов                   |
| subjects[].subject | string | Название предмета                  |
| subjects[].average | float  | Средний балл по предмету           |


### Пример запроса
``GET http://127.0.0.1:8000/api/reports/?class_id=1&quarter=1``
