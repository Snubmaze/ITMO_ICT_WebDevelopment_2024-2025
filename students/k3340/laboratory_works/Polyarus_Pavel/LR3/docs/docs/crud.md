# CRUD сущности

## Предметы
- `GET /api/subjects/`
- `POST /api/subjects/`
- `PUT /api/subjects/{id}/`
- `DELETE /api/subjects/{id}/`

## Учителя
- `GET /api/teachers/`
- `POST /api/teachers/`
- `PUT /api/teachers/{id}/`
- `DELETE /api/teachers/{id}/`

## Ученики
- `GET /api/students/`
- `POST /api/students/`
- `PUT /api/students/{id}/`
- `DELETE /api/students/{id}/`

## Кабинеты
- `GET /api/classrooms/`
- `POST /api/classrooms/`
- `PUT /api/classrooms/{id}/`
- `DELETE /api/classrooms/{id}/`

## Временные слоты (начало и конец урока)
- `GET /api/timeslots/`
- `POST /api/timeslots/`
- `PUT /api/timeslots/{id}/`
- `DELETE /api/timeslots/{id}/`

## Дни недели
- `GET /api/weekdays/`
- `POST /api/weekdays/`
- `PUT /api/weekdays/{id}/`
- `DELETE /api/weekdays/{id}/`

Все запросы требуют авторизации.
