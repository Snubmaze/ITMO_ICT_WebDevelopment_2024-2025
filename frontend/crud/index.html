    Справочники (CRUD)

    Описание

    Справочники — это базовые сущности системы. Для каждого справочника реализован полный набор CRUD-операций: просмотр списка, создание, редактирование и удаление записей.

    Архитектура

    Универсальный компонент CrudTable

    Компонент: components/CrudTable.vue

    Все справочники используют один универсальный компонент CrudTable, который настраивается через props:

    Prop Тип Описание
    title String Заголовок страницы
    icon String Класс иконки Bootstrap Icons
    columns Array Колонки таблицы [{ key, label }]
    api Object Объект с функциями getAll/create/update/remove
    formFields Array Поля формы [{ key, label, type, options? }]
    formatCell Function Кастомное форматирование ячеек
    prepareData Function Подготовка данных перед отправкой

    Фабрика API

    Модуль: api/crud.js

    Функция createCrudApi(endpoint) генерирует набор функций для любого эндпоинта:

    const subjectsApi = createCrudApi('/subjects/')
// subjectsApi.getAll()   → GET /subjects/
// subjectsApi.create({}) → POST /subjects/
// subjectsApi.update(1, {}) → PUT /subjects/1/
// subjectsApi.remove(1)  → DELETE /subjects/1/

    Поддерживаемые типы полей

    Тип HTML-элемент Пример
    text <input type="text"> Название предмета
    number <input type="number"> Номер урока
    time <input type="time"> Начало урока
    select <select> Тип предмета
    checkbox <input type="checkbox"> Спортзал (да/нет)
    multiselect <select multiple> Предметы учителя

    Справочники

    Предметы (/subjects)

    Компонент: SubjectsView.vue

    Поле Тип Описание
    name text Название предмета
    subject_type select Тип: Базовый / Профильный

    В таблице тип отображается цветным бейджем.

    Учителя (/teachers)

    Компонент: TeachersView.vue

    Поле Тип Описание
    last_name text Фамилия
    first_name text Имя
    middle_name text Отчество
    assigned_classroom select Закреплённый кабинет (FK)
    subjects multiselect Преподаваемые предметы (M2M)

    При загрузке страницы подтягиваются списки кабинетов и предметов для заполнения выпадающих списков.

    Ученики (/students)

    Компонент: StudentsView.vue

    Поле Тип Описание
    last_name text Фамилия
    first_name text Имя
    middle_name text Отчество
    gender select Пол: Мужской / Женский
    school_class select Класс (FK)

    Кабинеты (/classrooms)

    Компонент: ClassroomsView.vue

    Поле Тип Описание
    nubmer text Номер кабинета
    is_sports_hall checkbox Спортивный зал
    specialized_subjects multiselect Специализация (M2M)

    Классы (/classes)

    Компонент: ClassesView.vue

    Поле Тип Описание
    grade number Параллель (1–11)
    letter text Буква (А, Б, В...)
    class_teacher select Классный руководитель (FK)

    Оценки (/grades)

    Компонент: GradesView.vue

    Поле Тип Описание
    student select Ученик (FK)
    subject select Предмет (FK)
    value select Оценка (2–5)
    quarter select Четверть (I–IV)

    Оценки отображаются цветными бейджами: 5 — зелёный, 4 — синий, 3 — жёлтый, 2 — красный.

    Временные слоты (/timeslots)

    Компонент: TimeSlotsView.vue

    Поле Тип Описание
    lesson_number number Номер урока
    start_time time Время начала
    end_time time Время окончания

    Дни недели (/weekdays)

    Компонент: WeekdaysView.vue

    Поле Тип Описание
    name text Название (Понедельник...)
    order number Порядковый номер

    Модальные окна

    Создание / Редактирование

    При нажатии кнопки «Добавить» или иконки карандаша открывается модальное окно с формой. Поля заполняются динамически на основе formFields. При редактировании поля предзаполняются текущими значениями.

    Удаление

    При нажатии иконки корзины открывается диалог подтверждения. После подтверждения запись удаляется.

    Обработка ошибок

    Ошибки от сервера (DRF) автоматически распределяются по полям формы. Общие ошибки (non_field_errors, detail) отображаются над формой.
